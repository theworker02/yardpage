# yardpage

Yard encode/decode helpers for page payloads in pipelines.

**Site:** https://theworker02.github.io/yardpage/

## Install / run

```bash
git clone https://github.com/theworker02/yardpage.git
cd yardpage
node src/cli.js
node --test
```
